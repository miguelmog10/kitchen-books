# 0001. License: Apache 2.0 for everything in the repo (docs, schemas, rubrics, scripts)

- **Status:** Accepted
- **Date:** 2026-10-30

## Context

Kitchen Books (complexity accounting for codebases) is an open standard, so anyone must be able to reuse its docs, schemas, rubrics and scripts. The license was an open question in the kickoff and was settled with the first account's design. Source: [04-food-cost-account.md](../../dev/discovery/04-food-cost-account.md), "Other project decisions".

## Decision

License everything in the repo under Apache 2.0, as Knowledge Automata is.

## Consequences

- Permissive and commercial-friendly, with an explicit patent grant.
- One license for the whole repo: no separate terms for docs and code.
- Requires attribution. Templates copied from the principles repo are CC0, so they need none.
- Does not grant trademark rights, so the project name stays with the owner.
