# Kitchen Books

**Complexity accounting for codebases.** An open standard for tracking how a codebase's complexity grows compared with the scope it delivers, one pull request at a time.

Growth that matches scope is fine. Growth far beyond scope is a warning: features that were never removed, over-built changes, or agents that generate more than the task needed. Kitchen Books keeps the books, so that warning shows up on every pull request instead of years later.

## Status

Design done, repository setup next. The first account (complexity change versus scope change) is designed; the standard and a first test on [Knowledge Automata](https://github.com/miguelmog10/knowledge-automata) come next.
