# Costs

What each pull request cost, so the cost of AI-assisted work stays visible. The planner adds each pull request's row as the last commit on its branch, just before merging.

Cost is measured in time for now, not credits or money: the work runs on a subscription, and finding a useful cost measure is a playbook rule 8 experiment. Times come from the planner's review file and the implementer's report.
