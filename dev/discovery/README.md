These files are **frozen records**, like committed handoffs: they show what was decided and when, and they are not edited after they are committed. The living versions are the product docs that handoff 001 and later handoffs create from them (`standard/`, `docs/decisions/`). When a record and a later ADR disagree, the ADR wins.
